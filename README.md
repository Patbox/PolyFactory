# PolyFactory
PolyFactory is Fabric (and Quilt) server side modification powered by 
[Polymer](https://modrinth.com/mod/polymer) which adds new mechanics, blocks and tools allowing 
for further automation, processing, storage and more (or in simpler terms, it's a tech mod)!

![](https://cdn.modrinth.com/data/MikpSrAF/images/c9f682a402dba65fef2812de960456f42463b003.png)

Use Grinders, Mechanical Presses and other machines to process items into different, likely more
useful or compact items, transport them with lines of Conveyors and sort them out with Item Splitters
and Funnels. Smelt ores them in an Industrial Smeltery, transport fluids with Copper Pipes. Shoot them out with a Pressure Fluid Gun!
Power things with some Windmills, Steam Engines or Diesel Engines as using Hand Crank for everything won't take you far.

![](https://cdn.modrinth.com/data/MikpSrAF/images/d15b7efd3034a3b6cc5a92bd7bea721625bf8bb6.png)

Then, if you think you are done with machinery, you can use some Item Readers, Item Counters
connected to Nixie Tubes via colored Cables to display information in a nice and visible way!
Maybe even decorate your base with some Lamps and other blocks?

![](https://cdn.modrinth.com/data/MikpSrAF/images/3f8fa0fcb20af19468dba4dd25dff5c5cbd23a1e.png)

And if you need some utility? Get a Portable Drill for your mining endeavors, explode things with
Dynamite and then craft some Wooden Containers and Deep Storage Containers to store your items away. 
Use Workbench and Blueprint Workbench to make your crafting of singular items nicer.
And after a long week, take the Chain Lift to the mountains and eat some Cheese...

![](https://cdn.modrinth.com/data/MikpSrAF/images/a78dba41a444196beb5cfb7e10c1836254a9494d.png)

You don't know how to start? Use advancements, the guidebook and recipe book/[Polydex](https://modrinth.com/mod/polydex)
for help, as they should guide you through the mod!

## Extra mods you might want to use!
### Polydex
While not necessarily required, it's highly recommended to install [Polydex](https://modrinth.com/mod/polydex), as it allows
you to view all recipes in a simple interface. PolyFactory has full support for them,
with a shortcut button in all crafting station.

### Polymer AutoHost
Simplest way to handle automatic resource pack generation for your server!
While bundled by main distribution of [Polymer](https://modrinth.com/mod/polymer), it requires some manual
setup to work correctly. But it is quick and simple!

### PolyDecorations
Wanted to decorate your world a bit more? If so, this mod is ideal for you!
PolyDecorations is Fabric (and Quilt) server side mod which multiple decorative blocks such as benches, braziers and shelfs. [Checkout Modrinth page for more information!](https://modrinth.com/mod/polydecorations)
