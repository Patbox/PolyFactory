<yellow><lang 'item.polyfactory.canister'></> is a tool that can be used to easily pick up and move fluids.
<nl2>
It can store up to 2 buckets/blocks worth of fluid. It also can store different types of fluid at the same time,
through some of them might react with each other.
<nl2>
When interacting with blocks that allow in world fluid interaction, it will pour all fluid into the block.
<nl>
To extract fluid from them (if they allow it), attack the block while holding the Canister.
<nl>
You can change the top-most block by using the Canister while not targeting anything.
<nl>
The same controls also apply in gui interfaces.

### Header: Controls
### Align: Center
Use ['<key 'key.use'>] while not pointing at interactable block to change the order of fluids<nl>
Use ['<key 'key.use'>] while pointing at interactable block or fluid UI to pour top-most fluid into the container<nl>
Use ['<key 'key.attack'>] while pointing at interactable block or fluid UI to fill the Canister with top-most fluid from the container<nl>
