<yellow><item 'polyfactory:nixie_tube'></> is a data receiver block that can be used to display text in world.
This block can't receive data by itself and requires usage of <yellow><item 'polyfactory:nixie_tube_controller'></>.
<nl2>
Text color of <item 'polyfactory:nixie_tube'> can be changed by using a dye or a Spray Can on the block directly.
Additionally, you can use a renamed Name Tag to set its text without connecting it to the controller.
<nl2>
To connect a <item 'polyfactory:nixie_tube_controller'>, you need to place it in a way where it visually connects to the Nixie Tubes.
After than you can either connect cables and some data sources to the controller or configure it by using a <pageref '/basics/wrench'>.
Available options include the Channel, Facing direction, text scroll speed (0 disables it) and scrolling text looping
(whatever text should loop after the scroll finishes). With these you will be allowed to make interecting looking text displays.
